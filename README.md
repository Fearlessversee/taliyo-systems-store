> High-performance enterprise hardware and developer equipment e-commerce storefront featuring client-side cart state persistence, dynamic product filtering, and responsive glassmorphism UI.

---

## ⚡ Core Features

- **Dynamic Product Catalog**: Filter hardware components by category (Workstations, GPU Clusters, Monitored Displays, Peripherals).
- **Client-Side Cart Persistence**: Stateful shopping cart utilizing `localStorage` with real-time tax, shipping, and discount code recalculation.
- **Responsive Layout Engine**: Clean CSS Grid and Flexbox layout fully optimized across desktop, tablet, and mobile viewports.
- **Instant Product Search**: Zero-latency DOM search filtering across product titles and specifications.
- **Accessible Design**: Compliant with WCAG standards, ARIA labels, and keyboard navigation.

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5 with schema.org metadata
- **Styling**: Vanilla CSS3, CSS Custom Properties (Variables), Flexbox, CSS Grid
- **Scripting**: Vanilla JavaScript (ES6+), Event Delegation, LocalStorage API
- **Local Dev Server**: Standalone Python HTTP Server (`serve.py`)

---

## 🚀 Quickstart

```bash
# 1. Clone repository
git clone https://github.com/Fearlessversee/taliyo-systems-store.git
cd taliyo-systems-store

# 2. Launch local server
python serve.py
# Server runs at http://localhost:8880
```
